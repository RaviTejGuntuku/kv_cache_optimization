F1 · Declared required keys

Category: O · Proposed scope: Core

XGrammar: ✓ · llguidance: ✓ · JSONformer: ✓

Compile time: Easy: index declared keys and required set; O(S) for this flat object.

Generator runtime: Emit known keys; track k presence bits. Stack cost O(h).

Schema

{
  "type": "object",
  "properties": {
    "id": {
      "type": "string"
    }
  },
  "required": [
    "id"
  ],
  "additionalProperties": false
}

Valid instance

{
  "id": "a"
}

Invalid instance

{}
