## Interpretation

The shared practical gaps motivating the proposal are finite conditional fields, presence dependencies, simple exclusions, scoped uniqueness, bounded matching-item requirements, and compatible overlapping key constraints. Some can be rewritten into supported forms; missing keywords do not by themselves prove greater expressive power.

Sources: [Draft 2020-12 Core](https://json-schema.org/draft/2020-12/json-schema-core) and [Validation](https://json-schema.org/draft/2020-12/json-schema-validation). Format is annotation-only by default; content metadata does not automatically impose generation assertions. See the [saved evidence](evaluation.md#saved-baseline-evidence) for tests T12, T25, T37, T38, T39, T42, and T44.
